# A* Pathfinding Simulator

## Description
A 2D pathfinding simulator developed in Python using the A* search algorithm to find the shortest path between a starting point and a destination while avoiding obstacles.

## Features & How It Works
- Built using Python and the A* pathfinding algorithm
- Uses Manhattan distance to estimate the distance to the destination
- Uses Python's `heapq` library to prioritize which positions to explore
- Checks for obstacles and prevents movement outside the grid
- Tracks previous positions to reconstruct and display the shortest path

## What I Learned
Through this project, I learned more about how pathfinding algorithms work and how they can be used to navigate around obstacles. I also gained experience working with priority queues, heuristic functions, and implementing algorithms in Python.
